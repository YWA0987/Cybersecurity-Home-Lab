# Screenshot evidence

This folder is reserved for the sanitized lab screenshots supplied in the separate `Cybersecurity-Home-Lab-Starter.zip` package. Upload the PNG files into this directory (not the original internship PDFs). The [evidence index](../docs/evidence.md) lists the expected filenames and what each screenshot demonstrates.

Before publishing any new screenshots, check for personally identifying information, student identifiers, credentials, access tokens, and sensitive host/network details. The lab addresses in the documented private 192.168.50.0/24 segment are illustrative of this local configuration.
